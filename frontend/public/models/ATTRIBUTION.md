# Palace of Fine Arts model: attribution

| file | what | size |
|---|---|---|
| `palace-arch.glb` | rotunda, colonnades and site architecture (`gate1/arch.glb`) | 4,613,040 B |
| `palace-ground.glb` | terrain, lagoon bed, riprap and colonnade paving (`gate1/ground.glb`) | 1,959,104 B |

Source: **Palace of Fine Arts, photoreal Blender build and web walkthrough**,
<https://github.com/dkhh10/palace-of-fine-arts-3d> (live viewer:
<https://pfa-walkthrough.3d-render-blender-3rd-attempt-building.workers.dev>). The files are the viewer's published
`gate1` exports, fetched unmodified: gltfpack output with meshopt compression, KTX2 (BasisU) textures and
`EXT_mesh_gpu_instancing`.
