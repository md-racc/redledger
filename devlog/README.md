# Development history

These fragments and the frozen root `DEVLOG.md` document the Cal Hacks build. Preserve existing
entries and author attribution. They are historical notes; instructions and status inside old
entries may no longer apply. Use the current README and operations guide for local setup.

New maintenance fragments are optional. PR descriptions record current changes and validation.
`make devlog WHO=<Ad|Al|M|R> MSG="..." [SLUG=topic]` still creates a dated fragment, and
`make devlog-show` prints the combined history. Never append to `DEVLOG.md` or modify another
person's existing fragment. See `GIT.md`.
